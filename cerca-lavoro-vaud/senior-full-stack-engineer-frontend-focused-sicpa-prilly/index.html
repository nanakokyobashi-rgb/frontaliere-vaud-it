Descrizione completa

Per rafforzare il nostro dipartimento R&I DIGITAL, stiamo cercando un:

Senior Frontend & Fullstack Engineer

RUOLO

  • Progettazione, sviluppo e manutenzione di applicazioni web moderne, reattive e scalabili utilizzando Angular, TypeScript, NPM (Standard Package Manager) e CSS/SCSS.
  • Sviluppare ed evolvere architetture frontend, componenti riutilizzabili, framework web e librerie UI per applicazioni basate su microservice.
  • Contribuisci alla definizione e all'implementazione di standard UI/UX, guide di stile e migliori pratiche di frontend in allineamento con le linee guida di prodotto e aziendali.
  • Collabora a stretto contatto con sviluppatori backend, sviluppatori mobili, ingegneri DevOps, proprietari di prodotti, progettisti e altri stakeholder per fornire soluzioni digitali end-to-end.
  • Contribuisci allo sviluppo di backend quando necessario, utilizzando principalmente Spring Boot con Java e/o Kotlin.
  • Supporta la progettazione e l'integrazione di API RESTful tra applicazioni frontend, servizi backend, applicazioni mobili e database.
  • Applicare le best practice di ingegneria del software, tra cui test automatizzati, documentazione, peer code reviews, manutenbilità e codifica sicura.
  • Partecipa attivamente alle cerimonie Agile, alle discussioni sulla roadmap, ai workshop tecnici e alla pianificazione delle consegne.
  • Contribuisci alle pratiche CI/CD e alla distribuzione di applicazioni cloud-ready in collaborazione con DevOps e team di piattaforma.
  • Aiuta a garantire prestazioni, scalabilità, sicurezza, accessibilità e manutenbilità delle soluzioni digitali.
  • Lavorare in un ambiente di team Agile veloce e co-locato, dove feedback rapidi, condivisione delle conoscenze e stretta collaborazione sono fattori chiave di successo.

PROFILE

  • BS/MS laurea in Scienze informatiche, Ingegneria software o un campo tecnico correlato.
  • Provata esperienza come Senior Frontend Engineer o ruolo equivalente.
  • Forte competenza in Angular, TypeScript, NPM, HTML, CSS/SCSS.
  • Esperienza solida nella moderna architettura frontend, sviluppo basato su componenti e applicazioni web reattive.
  • Pratica esperienza di sviluppo backend con Spring Boot, preferibilmente utilizzando Java e/o Kotlin.
  • Buona comprensione del design RESTful API, modelli di integrazione e comunicazione sicura tra frontend e servizi backend.
  • Esperienza con test automatizzati, tra cui test di frontend e framework di test end-to-end come Karma, Jasmine, Selenium, Playwright o simili.
  • Familiarità con metodologie Agile e consegna in team di prodotti veloci e cross-funzionali.
  • La familiarità con le tecnologie dei container come Docker
  • Kubernetes o cloud platform experience è un vantaggio.
  • L'esperienza con database relazionali è un vantaggio.
  • La consapevolezza degli standard di accessibilità, compreso WCAG, è un plus.
  • Forte mentalità problem solving con la capacità di lavorare in modo indipendente pur rimanendo altamente collaborativo.
  • Imprenditoriale, curioso, pragmatico, affidabile e orientato al risultato.
  • Forte giocatore di squadra confortevole lavorare in un ambiente multiculturale.
  • Fluente in inglese; francese è un plus.
