Descrizione completa

Mission

The mission of the CIBM IT systems administrator and software developer is to provide high-level IT and administrative support to members of its community across the 5 founding partner institutions (CHUV, UNIL, EPFL, UNIGE, and HUG) and develop software which will contribute to achieve CIBM strategic objectives https://cibm.ch/the-center/

Main duties and responsibilities

  • Liaise with the IT services of partner institutions (CHUV, UNIL, EPFL, UNIGE, and HUG) to install, maintain, and integrate a biomedical imaging data platform
  • Develop and implement new features, adjust microservices on the biomedical imaging platform
  • Renewal, management, and ongoing monitoring of the IT infrastructure (servers, workstations)
  • IT management of websites and applications
  • Administration and user support of the infrastructure and resource booking system
  • Ensure the smooth operation of the various video-conferencing systems during events
  • Provide support and advice to users, evaluate and select software and IT equipment, procure and set up equipment, customize and configure software
  • Manage permissions, access rights, user accounts, and folder configuration for shared storage
  • Install and configure individual workstations and peripherals
  • Maintain and troubleshoot IT equipment: purchasing, inventory, and issue tracking
  • Set up and maintain backup policies for all of CIBM's critical shared machines (including non-standard machines such as scientific equipment) and advise on personal workstations
  • Set up and maintain enhanced security on CIBM's servers and sensitive machines (following IT security best practices)
  • Implement custom solutions (software and hardware) to meet the specific needs of CIBM's infrastructure
  • Create, maintain, and deploy specific internal applications (calendar, project, and purchasing management)

Technical environment & tools

Platform development & integration

  • Docker (images, registry), Git, GitLab (also CI/CD), Kubernetes (k8s), Pyhton

Application development

  • Next.js, Express, React, Mongo, Mysql, JavaScript, HTML, CSS

Systems & infrastructure

  • Windows, Linux, and Mac environments; hardware (processors, memory, graphics cards)
  • Server management: iDRAC, Proxmox
  • Storage management: Synology, QNAP
  • Authentication: keycloak, OIDC

Web & hosting

  • WordPress, Infomaniak interface, DNS, emails, SSL certificates

Collaboration & booking tools

  • Calpendo (resource booking)
  • Cisco, Zoom, Teams (video-conferencing)

Backup & security

  • Iperius, Veeam, rsync backup, Borg Backup
  • Log analysis tools, confidentiality rules, password management, patch management

Profile

  • Higher education degree in computer science (HES, university, or EPF) or equivalent qualification
  • Good knowledge of containerization and continuous integration tools (Docker, Git/GitLab, CI/CD); familiarity with Kubernetes
  • Basic scripting and task automation skills (bash)
  • Basic web development skills (JavaScript/HTML/CSS, frameworks such as Next.js/Express) a plus
  • Good knowledge of networks and IT infrastructure
  • Experience with Linux, Windows, Windows server (GPO/Active Directory), and Mac administration
  • Experience with network storage products (Synology, QNAP) a plus
  • Experience with virtualization (Proxmox) and remote server management (iDRAC) a plus
  • Strong knowledge of cybersecurity
  • Languages: French C1, English C1
  • Adaptable and autonomous
  • Strong sense of priorities and initiative
  • Ability to explain technical topics clearly and communicate with varied audiences
